## In plain words

Until today, the only way to watch the organism learn was to read numbers
out of a test log. Now there's a web page: you see the pattern being shown
on its 8×8 eye, its 160 brain cells flickering, its three answer meters
filling, the green flash when the teacher rewards it — and a live accuracy
chart climbing from guessing (33%) toward ~98% while you watch. There's a
speed dial, a pause button, and the important switch: turn *learning* off
and watch it keep answering correctly with no reward at all — the
living-model claim, performed live instead of asserted in a log.

Nothing scientific changed. The demo shows exactly the organism the
2026-08-16 gate certified — provably: the engine refactor needed for live
rendering reproduces the recorded learning curves digit for digit.

## Objective

Make experiment 001's M1 result demonstrable in a browser — an interactive
page a person can operate — before designing experiment 002.

None was pre-registered — the ask arose in conversation this morning

## Method

- **Engine refactor:** `AutoTeacher.runTrial` (which ran a whole trial in
  an internal loop) now delegates to a new tick-granular `TrialStepper`
  state machine (stimulus → judgment → blank), so a render loop can drive
  the world one tick at a time. One implementation of trial mechanics;
  `runTrial` is a `while (!step())` wrapper. Added a read-only
  `Organism.outputProbs()` accessor. No mechanism changes.
- **`src/demo-m1/sim.ts`:** DOM-free demo controller — same seed/schedule
  formula as the M1 test harness, tick-batched stepping, rolling accuracy,
  learning-toggle marks, pool-raster accumulation. Headless-tested.
- **`src/main.ts`:** rendering + controls only. Sense grid, pool raster,
  output register (policy-probability bars, spoken-vote pips, silence row,
  reward lamp), rolling-accuracy chart (chance 0.33 + gate 0.80 reference
  lines, learning-off shading, hover tooltip), stats strip, speed dial
  (60–24k ticks/s), learning toggle, seed + reset.
- **Design checks:** categorical trio for V/H/X validated with the dataviz
  six-checks script against the dark screen surface (`#3E8EDE #C08A18
  #DE5FA5` — all PASS; tritan pair 7.8 is in the requires-secondary-encoding
  band, satisfied since every mark carries a text label or glyph chip).
  Light/dark page themes; screens fixed dark. Rendered pages screenshotted
  headlessly (both themes) and inspected; two label-collision defects found
  and fixed.
- **Deliverables:** the Vite app page (`npm run dev`), and a self-contained
  single-file build (esbuild, 21 KB minified, zero dependencies, no network
  access) published as a private artifact:
  <https://claude.ai/code/artifact/1318cf33-a77e-4c86-b699-784f0c4f3c24>

## Results

- All 7 tests pass (~2.4 s): the original 4 M1 tests **unchanged**, plus 3
  new demo-path tests (gate at seed 1 tick-by-tick; retention ≥ 0.8 after
  toggling learning off at trial 500 via the demo API; reset determinism).
- The M1 suite's per-seed rolling-accuracy printouts after the stepper
  refactor are **bit-identical** to the curves recorded in
  [entry 2026-08-16-0248](./2026-08-16-0248-experiment-001-m0-m1-first-build.md)
  (e.g. seed 2: `0.54 → 0.80 → 0.87 → 0.94 → 0.96 → 0.95 → 0.97 → 0.98`;
  frozen retention `0.97`).
- Production build clean; bundle 23 KB (8.5 KB gzip).

## Analysis

The refactor is behavior-preserving by construction (single implementation)
and by evidence (identical curves — same RNG consumption, same tick
sequence). The demo therefore *demonstrates* the certified result rather
than a cousin of it. Worth noting for experiment 002: the `TrialStepper` is
also the seam where a **continuous-mode teacher** (tick-granular,
mid-exposure reward — the live-coaching experiment, ideas §A2) will plug
in; this build removes 002's main mechanism gap almost incidentally.

## Prior art & novelty

Nothing novel — engineering. The instrument-panel-for-a-learning-system
pattern is standard (TensorBoard lineage; interactive in-browser learners
like Karpathy's ConvNetJS demos are direct precedent). Cited for honesty,
not competition.

No new L-###. (L-007's headless-gate-first discipline paid again: the

## Decisions

1. **Demos are namespaced per milestone** — `src/demo-m1/`, `demo-m2` when
   MNIST lands (Javid, mid-build: a generic `src/demo/` mis-scales the
   moment a second demo exists).
2. **`runTrial` delegates to `TrialStepper`** — one implementation of trial
   mechanics forever; tests and UI can never drift apart.
3. Experiment 002 design proceeds next; its main engine prerequisite
   (tick-granular trial driving) now exists.

## Deviations

None from the operating gate. The build was UI-only by intent; no organism
or teacher *behavior* was altered.

## Threats to validity

1. **Interactive behavior is undertested.** Headless screenshots cover
   ~30 trials of rendering and two themes; the full 800-trial run, speed
   extremes, resize, and hover were reasoned about, not exercised by a
   human. First real session may surface UI defects (not science defects —
   those paths are tested).
2. **The demo shows seeds 1–3's certified regime;** other seeds presumably
   behave similarly but only 1–3 and 42 are test-covered.
3. The artifact link is private-by-default; the public record is the code
   in this repo, not the hosted page.
